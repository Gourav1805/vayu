# SatQuery → DEVLOK / VAYU transformation map

The source project is a static HTML/CSS/JavaScript product with scroll-led visual storytelling, mission/query interactions, a selectable agent workflow, cross-modal imagery comparison, temporal change exploration, spatial evidence panels, coordinate readouts, and a mission guide. The VAYU product uses those interaction ideas in an editorial scientific palette and preserves the prior experience. It has no backend, operational data ingestion, database, or trained model.

## Product boundary

VAYU's replay fixture is not live weather data. Its map, source ages, storm metrics, initiation candidate, and track are illustrative. The centroid route is a deterministic demonstration baseline; initiation is a separate conceptual branch and is not a trained predictor. Verification metrics are not computed. Lightning remains a likelihood proxy label; observed lightning is unavailable.
